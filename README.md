---

## ✨ Features Included

1. **Daily Overview HQ**: High-level command center displaying today's routines, hydration level, current book, scheduled calendar events, daily mood, and cashflow.
2. **Routines & Habit Building**: Categorized morning, evening, daily, and weekly habit checklists with streak tracking (🔥) and completion celebrations.
3. **Daily Meal Logs**: Track Breakfast, Lunch, Dinner, and Snacks with calories, nutritional tags (High Protein, Plant Power, Homemade), and preparation notes.
4. **Water Consumption Tracker**: Interactive hydration visualizer with quick preset buttons (+150ml, +250ml, +500ml, +750ml), customizable daily targets, and 7-day consistency chart.
5. **Budget & Spendings**: Net cashflow tracker with income inflows, categorized expenses (Groceries, Dining, Rent, Utilities, Fitness, etc.), and savings rate calculations.
6. **Library**: Personal reading library with page progression bars, star ratings, categorized statuses (*Currently Reading*, *Want to Read*, *Finished*), and quote notes.
7. **Daily Mood & Energy**: Emotional check-in tracking 5 mood states, energy level slider (1 to 5), influencing factor tags, and daily mindfulness reflections.
8. **Digital Junk Journal & Scrapbook**: Aesthetic scrapbook canvas with pastel color palettes, stickers (✨, ☕, 🌿, 🌙, 🕯️), songs on repeat, polaroid photo attachments, and pin-to-top memories.
9. **Hobbies & Craft Mastery**: Dedicated hobby logs tracking hours invested, skill levels, weekly goals, and milestone completion checklists.
10. **Exercise Plans & Workouts**: Structured training splits (Strength, Cardio, Mobility/Yoga, HIIT, Pilates) with exercise sets/reps logs and session tracking.
11. **Ideas & Future Plans**: Vision board and Kanban pipeline (*Sparks*, *Planning*, *In Progress*, *Achieved*) with priority flags and sub-action checklists.
12. **Personal Calendar & Agenda**: Interactive monthly calendar with color-coded event tags, start/end times, and day-by-day agenda views.
13. **Local Persistence & JSON Backup**: All data is automatically saved locally in your browser with zero server setup required. Includes 1-click **Export Backup JSON** and **Import JSON** restore.

## 🚀 Quick Start

### 1. Start Development Server
```bash
npm run dev
```
Open your browser at [http://localhost:5173](http://localhost:5173).

### 2. Build for Production
```bash
npm run build
npm run preview
```

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS (Dark Mode Elegant Palette)
- **Icons**: Lucide React
- **Celebration Animations**: Canvas Confetti
- **Storage**: Browser LocalStorage + JSON Export/Import
